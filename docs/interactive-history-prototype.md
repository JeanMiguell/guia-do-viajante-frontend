Create a **low-fidelity UI prototype** for an educational web application called **Atlas Histórico Interativo**.

The system is an **interactive educational tool (not a game)** designed to help students explore historical events through a **map-based interface combined with quizzes**.

The interface should be **clean, modern, and simple**, suitable for students between **12–16 years old**.
Use a **map-exploration style similar to Google Maps or Duolingo learning flows**.

Main color palette suggestion:

* dark blue or navy (primary)
* light background
* accent color for interactions (orange or yellow)

Typography should be **clear and readable for educational purposes**.

The prototype should include the following screens:

---

SCREEN 1 – Home Screen

Title: **Atlas Histórico Interativo**

Description text:
"Explore os principais eventos da história do Brasil através de mapas interativos."

Elements:

* Large title at the top
* Short description below
* Primary button: **Explorar História**
* Illustration or background showing a historical map

Navigation flow:
User clicks **Explorar História** to continue.

---

SCREEN 2 – Historical Period Selection

Title: **Escolha um período histórico**

Display the following options as **cards or buttons**:

* Brasil Colônia (1500–1822)
* Brasil Império (1822–1889)
* Primeira República (1889–1930)
* Era Vargas (1930–1945)
* Ditadura Militar (1964–1985)
* Nova República (1985–presente)

Each card should include:

* period name
* short subtitle
* clickable interaction

When a period is selected → navigate to the map screen.

---

SCREEN 3 – Interactive Map Screen

Title: **Mapa Histórico**

Display a **map of Brazil** with clickable markers representing historical events.

Example markers:

* Independência do Brasil (1822)
* Guerra do Paraguai
* Abolição da Escravidão (1888)

UI elements:

* zoomable map
* clickable markers
* sidebar showing event list
* back button to return to period selection

Clicking a marker opens the event details screen.

---

SCREEN 4 – Historical Event Page

Example event: **Independência do Brasil (1822)**

Layout elements:

* Event title
* Short historical description (2–3 sentences)
* Section called **Personagens Históricos**

  * Dom Pedro I
  * José Bonifácio
* Historical image placeholder
* Map location preview
* Button: **Iniciar Quiz**

This screen is designed to help students understand the event before testing knowledge.

---

SCREEN 5 – Quiz Screen

Title: **Quiz de Fixação**

Display a multiple choice question.

Example question:

"Em que ano ocorreu a Independência do Brasil?"

Options:

* 1500
* 1822
* 1889
* 1808

Components:

* question card
* radio button options
* submit button: **Responder**

After answering → navigate to result screen.

---

SCREEN 6 – Quiz Result Screen

Title: **Resultado do Quiz**

Example text:
"Resposta correta!"

Show:

* number of correct answers
* progress indicator

Buttons:

* **Explorar mais eventos**
* **Voltar ao mapa**

---

Design guidelines:

* Educational and intuitive UI
* Simple navigation
* Map-based exploration experience
* Clear hierarchy of information
* Mobile and desktop responsive layout
* Minimalist educational style

Focus on creating **wireframes for all six screens** showing navigation flow between them.
